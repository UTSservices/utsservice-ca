Questions

Questions people ask us

Can an existing door be made automatic?

Often, yes. A swing door operator can be fitted to many existing doors, with a push button or sensor to trigger it. We check the door, frame and power supply first to confirm it will work.

Sliding or swing: which automatic door do I need?

Sliding doors suit wide entrances with constant traffic, like lobbies and storefronts. Swing operators suit a single existing door, and cost less because the door and frame stay.

Do automatic doors need regular service?

Yes. Sensors, motors and safety features wear with use. Regular checks keep the door safe and catch problems before the entrance goes out of service.

Do push-button openers help with accessibility?

Yes. A power operator with a push button is a common way to make an entrance barrier-free, which many Ontario buildings are required to provide. We install hardware that meets the code requirements for your building.
